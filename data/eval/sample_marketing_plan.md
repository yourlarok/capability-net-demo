# 营销视频诊断与改进

> 任务：我们公司的产品宣传视频播放量很低，帮我出一个完善的视频改进计划
> 工作流 `marketing-video-improve` · 匹配度 0.52 · 来源 expert-curation（效果广告/短视频运营通行方法：漏斗分层诊断 + 留存曲线拉片 + 爆款拆解 + 单变量 A/B 验证；待真实轨迹校准）
> 槽位覆盖 100% · 可自动执行槽位 44%

## 开工前需要你提供
- 现有视频文件或链接（至少 1 条，最好近期 5–10 条）
- 视频目标：品牌曝光 / 涨粉 / 线索 / 直接转化，选一个北极星指标
- 后台数据：播放、完播率、5 秒完播、留存曲线；投放过的话再加 CTR / CVR / CPA
- 产品核心卖点、目标人群、价格带
- 预算与改版周期（决定 A/B 测试能跑多大样本）

## 1. 目标与基线 — 锁定一个北极星指标，判断问题出在漏斗哪一层
1. 按目标选主指标：曝光类看完播率/互动率，转化类看 CTR→CVR→CPA；只设 1 个主指标 + 2 个护栏指标
2. 导出近期视频数据建基线表，与账号均值、同行业均值对比
3. 分层定位：曝光层（封面/标题/推流量低）→ 观看层（3 秒、5 秒流失高）→ 转化层（看完不点、点了不买）
4. 只攻最上游的断点：上游漏了，下游优化无意义

**交付物**：指标基线表 + 问题所在漏斗层级的判断
**验收/指标**：每个指标有具体数值与对比基准；明确写出'问题主要在 X 层'

*工具槽 `analytics`*（data.analytics）：
  - **抖音创作者服务中心**（推荐） [人工使用·gui] — 抖音官方后台：单条视频播放、完播率、5 秒完播、跳出时间点、粉丝画像。
  - **B站创作中心** [人工使用·gui] — B站官方后台：播放、观众留存曲线、互动、流量来源。
  - **YouTube Analytics API** [agent 可调用·api] — 按视频拉取观看时长、观众留存（audienceWatchRatio）、流量来源等指标，OAuth 授权后可程序化调用。

## 2. 逐秒拉片诊断 — 把留存曲线上的每个跌点对齐到具体画面和台词
1. 标出留存曲线跌点：第 1–3 秒、第 5 秒，以及每一处斜率陡增的时间点
2. 把跌点对齐到画面/口播/字幕，逐一写原因假设
3. 按'钩子—冲突/痛点—价值—证明—行动号召'结构检查缺哪一环、顺序是否错位
4. 常见病：首帧无信息、开场自我介绍、卖点出现过晚、字幕过小、BGM 盖过人声、CTA 模糊或缺失

**交付物**：带时间戳的问题清单（时间点 / 现象 / 原因假设 / 严重度）
**验收/指标**：每个跌点都有对应原因假设；问题按严重度排序

*工具槽 `video-understand`*（video.understand）：
  - **Gemini 视频理解 API**（推荐） [agent 可调用·api] — 直接输入视频，按时间戳描述画面、口播、节奏，可做逐秒内容诊断。

## 3. 竞品与爆款拆解 — 找到同赛道已验证有效的结构，而不是凭感觉改
1. 选同赛道近 30 天 5–10 条爆款与 2–3 个对标账号
2. 逐条拆：前 3 秒钩子类型（反常识/痛点提问/结果前置/冲突）、时长、镜头密度、卖点出现顺序、CTA 形式
3. 扫评论区高频词：用户真正在意什么、在质疑什么
4. 提炼 2–3 个可迁移的结构模板

**交付物**：爆款拆解表 + 可迁移结构模板
**验收/指标**：样本 ≥5 条且注明数据来源与时间；模板能直接套到自己的产品上

*工具槽 `research`*（data.research）：

  - **蝉妈妈** [人工使用·gui] — 抖音电商数据：商品、直播间、带货视频排行与转化数据。
  - **飞瓜数据** [人工使用·gui] — 抖音/快手/B站 爆款视频、达人、带货数据库，拆解同类爆款与竞品账号。

## 4. 改进假设与改版脚本 — 把问题变成可验证的假设，按 ICE 排优先级
1. 每个问题写成假设：'如果把 X 改成 Y，主指标会从 a 提升到 b，因为……'
2. 按影响 × 信心 ÷ 成本（ICE）排序，先做前 3 条
3. 每个版本只改 1–2 个变量，否则无法归因
4. 产出改版脚本：3 个不同钩子的开头 + 精简版（压到原时长 60–70%）+ 3 套标题/封面文案

**交付物**：假设表（含 ICE 分）+ 改版脚本
**验收/指标**：每条假设对应一个可测指标；版本间变量互不重叠

*工具槽 `copywriting`*（text.copywriting / text.writing）：
  - **Claude API**（推荐） [agent 可调用·api] — 长文本推理与写作：脚本诊断、钩子/标题/文案多版本生成、复盘报告。
  - **Sudowrite** [人工使用·gui] — 面向小说创作的 AI 写作平台，续写/扩写/风格化见长。需人工操作。

*工具槽 `user-voice`*（research.user）：
  - **问卷星**（推荐） [人工使用·gui] — 在线问卷与调研：用户反馈、满意度、需求调研。
  - **用户访谈 / 焦点小组** [人工使用·manual] — 5–8 位目标用户一对一访谈或焦点小组，挖动机与反对理由。

## 5. 改版制作 — 按脚本重剪，做出可测试的多个版本
1. 首帧放结论/结果/冲突画面，删掉开场寒暄与 logo 片头
2. 卖点前置到 5 秒内，删冗余镜头，提高镜头密度
3. 大字号字幕 + 关键词高亮，确保静音也能看懂
4. 人声清晰优先，BGM 压在人声之下；结尾给明确 CTA
5. 同步做 3 套封面（同一视频不同封面便于测试）

**交付物**：3–4 个改版视频 + 3 套封面
**验收/指标**：每个版本与假设表一一对应；静音观看信息完整

## 6. A/B 投放验证 — 用真实流量判断哪个版本赢
1. 同预算、同人群、同时段并行投放原版与各改版
2. 每版达到最小样本再判（例如 ≥100 次点击或 ≥5000 次曝光，按平台调整），不提前看结果下结论
3. 看主指标的同时检查护栏指标（如 CTR 升了但 CVR 掉了 = 标题党）
4. 比例类指标用置信区间判差异，区间重叠就继续跑或判平

**交付物**：A/B 结果表：各版本主指标、护栏指标、置信区间、胜负判定
**验收/指标**：胜出版本主指标显著优于原版；护栏指标未恶化

*工具槽 `abtest`*（ads.abtest / ads.campaign）：
  - **巨量引擎广告投放**（推荐） [人工使用·gui] — 抖音/头条信息流投放平台：多素材分组测试、人群定向、CTR/CVR/CPA 报表。
  - **YouTube Studio 测试和比较** [人工使用·gui] — 同一视频上传最多 3 个封面（及标题）做 A/B 测试，按观看时长份额判胜。
  - **巨量千川** [人工使用·gui] — 抖音电商广告：短视频/直播间引流投放，ROI 与 GMV 报表。

## 7. 复盘与沉淀 — 把这一轮学到的东西变成下一轮的默认做法
1. 逐条标注假设被证实 / 证伪 / 不确定
2. 胜出的结构写进账号脚本模板，证伪的写进'别再做'清单
3. 规划下一轮：从剩余假设里按 ICE 再取 3 条

**交付物**：复盘报告 + 更新后的脚本模板
**验收/指标**：每条假设都有结论；模板已更新

*工具*：无需外部能力，agent 按上述方法直接完成。
