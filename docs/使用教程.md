# capnet 使用教程

capnet 是一个"能力与工作流路由网络"：agent 遇到多步骤的专业任务时，先向它要一份**成熟工作流 + 每一步该用什么工具**的计划；任务做完后，可以在用户同意的前提下，把清理过的"客观解决思路"回传，帮网络归纳新工作流、校准工具排名。

- 路由对所有人完整开放，**上不上传轨迹都不影响任何结果**。
- 零第三方依赖，只要 Python 3.11+。

---

## 1. 在任意项目里接入（5 分钟）

下文用 `<CAPNET>` 指仓库所在路径，例如 `D:/capability-net-demo`。

### 1.1 获取代码

```bash
git clone -b v3-traces https://github.com/yourlarok/capability-net-demo.git
cd capability-net-demo
python demo.py plan "抖音视频完播率低，怎么改"     # 能输出计划就说明可用
```

### 1.2 注册 MCP 服务（全局，所有项目都能用）

```bash
claude mcp add capnet --scope user -- python <CAPNET>/demo.py mcp
```

- 路径必须写绝对路径。仓库自带的 `.mcp.json` 用的是相对路径，只在仓库目录里生效。
- 只想在某一个项目里用：进入那个项目，把 `--scope user` 换成 `--scope project`。这会在该项目生成 `.mcp.json`，可以提交给团队。
- 检查是否注册成功：`claude mcp list` 里应该能看到 `capnet ... ✓ Connected`。
- 其他支持 MCP 的客户端（Cursor、Cline、Claude Desktop 等）配置方式相同：命令 `python`，参数 `["<CAPNET>/demo.py", "mcp"]`，传输方式 stdio。

### 1.3 安装 skill（告诉 agent 什么时候用、怎么用）

把 `<CAPNET>/.claude/skills/capnet/` 整个目录复制到 `~/.claude/skills/capnet/`。

```bash
# Git Bash / macOS / Linux
mkdir -p ~/.claude/skills && cp -r <CAPNET>/.claude/skills/capnet ~/.claude/skills/
```

```powershell
# PowerShell
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse -Force "<CAPNET>\.claude\skills\capnet" "$HOME\.claude\skills\"
```

不装 skill 也能用：MCP 服务在握手时会下发一段简要说明。但 skill 里写清了"人工工具不能假装调用"和"上传必须先征得同意"等规范，建议安装。

### 1.4（可选）私有词表

新建 `~/.capnet/private_terms.txt`，每行写一个不想外传的词，比如公司名、产品名、客户名、同事姓名。汇总轨迹时，这些词会被替换成 `[私有]`。

```
ACME
小熊保温杯
王大锤
```

Windows 上 `~` 指 `C:\Users\<你>\`。

## 2. 试一下

在**任意其他项目**里打开 Claude Code，直接提需求：

> 我们的护肤品抖音视频播放量一直上不去，帮我出一个完整的视频改进计划

agent 应该会：

1. 调用 `plan_task`，返回"营销视频诊断与改进"工作流。工作流共 7 个阶段，每个阶段写明目标、方法、交付物和验收指标，并为每个工具位推荐工具（按国内/海外市场区分）。
2. 先向你要计划里"开工前需要你提供"的材料，比如后台数据、视频文件。
3. 按阶段推进：标着"agent 可调用"的工具可以直接用；标着"人工使用"的工具（剪映、巨量引擎后台这类 GUI 工具）只会推荐给你，由你自己操作。

其他可以试的问题：

| 领域 | 示例提问 |
|---|---|
| 电商 | 新品保温杯要上淘宝，帮我规划主图视频和详情页短视频 |
| 账号增长 | 想做一个讲职场的个人 IP 账号，从 0 起号怎么做 |
| 品牌 | 新茶饮品牌秋季上新，做一波全网传播 |
| 课程 | 把我的 Excel 培训讲义做成一套 10 节的网课视频 |
| 播客 | 做一期 40 分钟的科技访谈播客，从选题到发布 |
| 直播 | 昨晚直播 GMV 掉了一半，帮我复盘 |
| 短剧 / 游戏 / 解说 | 做一集 2 分钟的 AI 短剧 / 做一个网页小游戏 / 把这部电影做成解说视频 |
| 不该走工作流的 | 播客耳机推荐哪款？（应直接回答，不出计划） |

也可以点名调用：

- "用 capnet 查一下有什么能自动转字幕的工具"，对应 `find_capability`。
- "列出 capnet 的所有工作流"，对应 `list_workflows`。

### 6 个 MCP 工具一览

| 工具 | 作用 |
|---|---|
| `plan_task(query, task_type?, market?)` | 任务 → 工作流 → 逐阶段方法 + 工具推荐。`task_type`：produce / improve / grow / launch / review / qa；`market`：cn / global |
| `find_capability(query, domain?, k?, market?)` | 只缺一个能力时，查合适的工具 |
| `list_workflows(industry?)` / `get_workflow(workflow_id)` | 浏览工作流库 |
| `summarize_trace(...)` | 把执行记录整理成清理后的预览，**不上传** |
| `submit_trace(preview_id, consent)` | 用户确认后上传；`consent=false` 会删除本地预览 |

## 3. 回传思路（可选，必须经你同意）

任务做完后，agent 可能会问你要不要回传这次的解决思路。流程是：

1. agent 调用 `summarize_trace`，在**本地**生成清理后的预览，然后把预览原样展示给你。预览里会列出被清理掉的内容；可能还有风险的地方会标 ⚠。
2. 你选择：**同意上传** / **不上传** / **我先改一下**。
3. 只有你明确同意，才会上传。上传的内容必须和你看到的预览完全一致，系统用指纹校验，被改过就拒收。

**会上传的**：问题类型（例如"营销视频播放量低"）、每一步的领域、工具 id、是否成功、返工次数、一句话方法，以及可迁移的经验。

**不会上传的**：

- 任务原文、产出内容、成本、精确时间（只精确到天）；
- 注册表之外的工具名；
- 密钥、邮箱、电话、证件号、卡号、IP、文件路径、链接、@账号、金额、《作品名》、"张总 / 李经理"这类称谓，以及你私有词表里的词。

你的身份只表现为本机随机安装 id 的哈希。

> ⚠ 规则无法识别任意人名和公司名，所以请认真看一眼预览，并把敏感专名写进私有词表。

### 上传到哪里

| 情况 | 去向 |
|---|---|
| 没设 `CAPNET_HUB_URL` | 写入本机的 `<CAPNET>/data/hub/`，你自己的机器就是汇总端 |
| 设了 `CAPNET_HUB_URL=http://某地址:8765` | POST 到那台机器上运行的 hub |

想让别人的轨迹汇总到你这里：

```bash
# 你的机器（汇总端）
python demo.py hub serve --host 0.0.0.0 --port 8765
```

```bash
# 接入者注册 MCP 时带上环境变量
claude mcp add capnet --scope user -e CAPNET_HUB_URL=http://<你的IP>:8765 -- python <CAPNET>/demo.py mcp
```

hub 收到轨迹后，会在服务端再清理一遍、去重，然后立刻把这些结果计入工具排名。

## 4. 汇总端运营（给网络维护者）

```bash
python demo.py hub stats                 # 收到多少轨迹、多少贡献者
python demo.py hub refresh               # 从轨迹归纳工作流草稿（默认至少 3 位独立贡献者、成功率 ≥ 0.6）
#   → 草稿写到 data/workflows_drafts/，人工审核
python demo.py promote <workflow_id>     # 审核通过，移入正式库 data/workflows/
python demo.py gaps                      # 大家问了、但注册表答不上来的能力缺口
python demo.py eval --file data/eval/blind.json   # 改了工作流或打分后跑回归评测
```

### 自己加一个工作流

参照 `data/workflows/marketing-video-improve.json` 写一个 JSON，放进 `data/workflows/`：

- 每个阶段：`goal / method / deliverable / checks`；
- 每个工具位：`slot_id / domain`，可选 `alt_domains`；
- `intents`：用户会怎么描述这类任务。

写完后用 `python demo.py plan "<你的典型提问>"` 看能不能命中。

### 自己加工具卡

往 `data/catalog/*.json` 里加卡片，字段参照 `business.json`。`markets` 写 `["cn"]`、`["global"]` 或两者都写；`transport` 写 `api` / `cli` / `mcp`（agent 可调用）或 `gui` / `manual`（人工使用）。

## 5. 环境变量

| 变量 | 默认 | 作用 |
|---|---|---|
| `CAPNET_HOME` | `~/.capnet` | 安装 id、私有词表、待确认预览（`pending/`） |
| `CAPNET_PRIVATE_TERMS` | `~/.capnet/private_terms.txt` | 私有词表路径 |
| `CAPNET_HUB_URL` | 空 | 远端 hub 地址，空表示写本机 |
| `CAPNET_HUB_DIR` | `<CAPNET>/data/hub` | 本机 hub 数据目录 |
| `CAPNET_DRAFTS_DIR` | `<CAPNET>/data/workflows_drafts` | 归纳出的工作流草稿目录 |

## 6. 常见问题

- **`claude mcp list` 显示连接失败**：先在终端单独跑 `python <CAPNET>/demo.py mcp`，确认不报错（它会安静地等待输入，用 Ctrl+C 退出）。另外确认 `python` 指向 3.11 及以上版本；Windows 上可以把命令换成 `py`。
- **agent 不调用 capnet**：确认 skill 已复制到 `~/.claude/skills/capnet/SKILL.md`；或者在提问里直接说"用 capnet"。
- **英文提问匹配不上**：当前检索只支持中文，这是已知限制。
- **问题没命中任何工作流**：agent 会按常识自行拆解；这次查询会记进缺口日志，可以用 `python demo.py gaps` 查看。
